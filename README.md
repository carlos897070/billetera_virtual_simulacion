# 💳 Billetera Virtual

## Descripción

**Billetera Virtual** es un trabajo práctico desarrollado en **Java** que simula el funcionamiento de una plataforma financiera digital.

El sistema permite administrar usuarios, empresas y cuentas virtuales, realizar transferencias de dinero e inversiones, aplicando distintas reglas de negocio y validaciones para garantizar la consistencia de las operaciones.

El proyecto fue desarrollado utilizando programación orientada a objetos, haciendo uso de herencia, polimorfismo, interfaces, clases abstractas y colecciones del Framework de Java.

---

## Funcionalidades

### 👤 Gestión de usuarios
- Registro de usuarios.
- Consulta de cuentas asociadas.
- Administración de datos personales.

### 🏢 Gestión de empresas
- Registro de empresas.
- Asociación de personas autorizadas.
- Creación de cuentas corporativas.

### 💰 Administración de cuentas
- Creación de cuentas:
  - Cuenta Regular
  - Cuenta Premium
  - Cuenta Corporativa
- Consulta de saldo.
- Validación de alias y CVU.

### 💸 Transferencias
- Transferencias entre cuentas.
- Validación de fondos disponibles.
- Registro del historial de operaciones.

### 📈 Sistema de inversiones
El sistema permite realizar distintos tipos de inversiones, entre ellas:

- Renta Fija
- Fondo de Liquidez Empresarial
- Inversiones vinculadas a divisas

Cada inversión posee sus propias reglas de funcionamiento y cálculo.

### 📊 Historial de operaciones
- Registro de movimientos realizados.
- Consulta del historial de transacciones.
